iccmonit v2

Visêo consolidada das sessões Claude Code, da máquina e dos serviços locais — com recursos sensíveis desativados por padrêo.

Ver no GitHub Como instalar

Local primeiro

O modo web usa somente 127.0.0.1. Acesso remoto é feito com túnel SSH.

Privacidade

Chat, transcripts e logs sêo opt-in. Caminhos completos e IDs nêo entram no prompt geral.

Controle

Ações Docker e probes de autenticaçêo ficam bloqueados até habilitaçêo explícita.

Começar

git clone git@github.com:linnoff88-dev/iccmonitv2.git
cd iccmonitv2
./start.sh

Modo web local

./start.sh web
# acesso remoto seguro:
ssh -L 8000:127.0.0.1:8000 usuario@maquina
